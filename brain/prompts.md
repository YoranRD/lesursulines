## Prompt homepage
Create or improve the homepage for Les Ursulines.

Priority:
1. explain that it is a real vegan restaurant in Dieppe;
2. make the daily menu and Instagram logic clear;
3. make phone, reservation and location obvious;
4. show real food and atmosphere images;
5. communicate homemade, warm, inclusive and local identity;
6. introduce brunch, petit déjeuner & douceurs, story, Gina and group meals.

The homepage must quickly communicate:
- what Les Ursulines is;
- where it is;
- when people can come;
- what they can eat;
- what to do next.

## Prompt Carte
Create or improve the Carte page.

Important:
The dishes change regularly with seasons. Do not invent a fixed menu.
Explain the system, show examples through images, include drinks / petit déjeuner / desserts, and make phone + contact CTAs very visible (Instagram is NOT the systematic source of the daily menu).

Use `menu-les-ursulines.webp` (the new official menu image) when useful.

## Prompt Brunch
Create or improve the Brunch page.

Goal:
- make Sunday brunch desirable;
- explain reservation;
- mention groups, birthdays, EVJF and private brunches;
- keep the tone warm and simple;
- avoid party/event-club positioning.

## Prompt À propos
Create or improve the À propos page.

Tell the story of Frédérique Diarra and Delphine Chevalme without cliché.
Explain the values: homemade, vegan, culture, respect for life, inclusion, welcome.
Include Gina as a subtle mascot.

## Prompt Boutique
Create or improve the Boutique page.

Phase 1 constraints:
- no real checkout yet;
- no fake products;
- prepare future products, cakes, orders and click-and-collect;
- make it feel curated and local, not aggressive e-commerce.

## Prompt Journal
Create or improve the Journal page.

Editorial direction:
- useful local SEO;
- vegan food in Dieppe;
- brunch;
- culture;
- local products;
- behind the scenes;
- warm, useful, readable;
- not generic filler.

## Prompt Contact
Create or improve the Contact page.

Priority:
- phone click-to-call;
- address;
- hours;
- itinerary button;
- Instagram;
- reservation / group / cake-order form;
- email fallback.

Do not create a fake working form if Web3Forms key is missing. Mark TODO clearly.

## Prompt design page
Design this page using the local Les Ursulines brain.
Goal:
- warm, botanical, cultural, handmade;
- clear hierarchy;
- generous spacing;
- real images;
- simple but polished UI;
- no cold corporate look;
- no generic restaurant template;
- no fake luxury.

Use the closest palette from `brain/wada-palettes.md`, especially Wada Olive Rose 22, Tea Leaf 23 or Forest Dust 25.

## Prompt QA
Before considering the page done, verify:
- the page says “restaurant végétalien” clearly;
- phone, hours and address are easy to find;
- mobile UX is strong;
- menu logic does not pretend the daily dishes are fixed;
- palette matches warm botanical identity;
- photos are real and useful;
- text is welcoming, not militant;
- SEO title and description exist;
- image alt text exists;
- build passes.
