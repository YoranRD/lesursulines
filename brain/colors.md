# Colors — Les Ursulines

## Intention palette globale
Le site doit partir sur une palette :
- végétale ;
- douce ;
- chaude ;
- légèrement vintage ;
- culturelle ;
- lisible ;
- jamais criarde.

Le logo est noir et blanc, mais le site ne doit pas être seulement noir et blanc. Le noir sert au contraste, au logo et aux détails graphiques. L’atmosphère globale doit être plus chaude.

## Palette recommandée
Partir en priorité d’une combinaison inspirée de :
- `Wada Olive Rose 22`
- `Wada Tea Leaf 23`
- `Wada Forest Dust 25`

Ces palettes sont pertinentes car elles associent :
- vert olive / sauge : végétal, naturel, calme ;
- beige / crème : table, pain, pâtisserie, chaleur ;
- brun / rosé / terracotta : cuisine, café, bois, humain ;
- bleu-gris / charbon : lisibilité, façade, enseigne, sérieux.

## Couleurs de travail suggérées
À ajuster lors de l’implémentation si besoin :

- Fond principal : `#F4E9E0` ou `#F0EBE1`
- Fond secondaire clair : `#F7F2EA`
- Vert olive principal : `#7B8262` ou `#6E7B63`
- Vert profond / footer : `#5E6A57` ou `#33404D`
- Accent chaud : `#C08478` ou `#BA8A63`
- Brun café / texte chaud : `#4B3F3A`
- Texte principal : `#2F332C` ou `#29312B`
- Texte secondaire : `#6C7480`
- Ligne / bordure : `rgba(47, 51, 44, 0.16)`

## Logique d’usage
- Fond principal : crème / papier chaud.
- Sections alternées : sauge pâle, rose doux, crème plus clair.
- CTA principal : vert olive profond ou brun chaud selon contraste.
- CTA secondaire : transparent avec bordure.
- Footer : vert profond ou charbon végétal.
- Badges : accent chaud discret.
- Logo : conserver noir / blanc, ne pas recolorer abusivement.

## Combinaisons utiles
### Home / hero
- fond crème ;
- texte brun / charbon ;
- CTA vert olive ;
- accent chaud sur badge ou soulignement.

### Carte / menu
- fond crème ;
- cartes blanches cassées ;
- titres vert olive ;
- détails façon ardoise en charbon.

### À propos
- fond rosé doux ou beige ;
- images vintage ;
- accents terracotta.

### Brunch / groupes
- fond lumineux ;
- CTA chaud ;
- détails botaniques.

### Footer
- vert profond ou charbon ;
- texte crème ;
- logo en blanc ou version adaptée.

## Règles d’usage
- Ne jamais utiliser plus de 3 couleurs fortes dans une même section.
- Conserver un contraste WCAG correct.
- Ne pas rendre le site trop vert.
- Ne pas rendre le site trop beige vide.
- Utiliser les couleurs comme atmosphère, pas comme décoration gratuite.

## Interdits
- vert néon ;
- pastel trop enfantin ;
- noir et blanc uniquement ;
- rouge agressif ;
- dégradés tech ;
- palette luxe noire et dorée ;
- couleurs modernes gadget déconnectées du lieu.

## Référence Wada
Le fichier `wada-palettes.md` sert de bibliothèque. La règle générale est de choisir d’abord une palette existante proche de la demande, puis d’adapter légèrement si nécessaire, en privilégiant harmonie, nuance et contraste utile.
