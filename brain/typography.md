# Typography — Les Ursulines

## Contraintes
- Ne pas modifier le logo.
- Ne pas recréer la typographie du logo en faux.
- La typographie UI doit dialoguer avec l’univers manuscrit / ardoise sans rendre tout le site manuscrit.
- Maximum deux familles typographiques.

## Direction recherchée
Le site doit combiner :
- des titres chaleureux, éditoriaux, légèrement vintage ;
- un texte courant très lisible ;
- une sensation artisanale mais professionnelle ;
- une bonne lisibilité mobile.

## Décision finale (validée)
- Titres : `Cormorant Garamond`
- Texte courant : `Source Sans 3`
- Accent manuscrit court : `Caveat`

Cette combinaison est retenue définitivement. Ne pas substituer par DM Serif Display, Manrope ou Inter sans nouvelle validation explicite.

### Justification
Cormorant Garamond + Source Sans 3 s’aligne avec les photos vintage, les assiettes fleuries et l’identité culturelle et éditoriale du lieu. Caveat est choisie pour les accents manuscrits car elle reste lisible à petite taille et cohérente avec l’univers ardoise.

## Usage de Caveat (accent manuscrit)
Caveat est autorisée uniquement pour :
- très petites annotations (ex. "Fait maison", "Du marché") ;
- badges ou étiquettes courtes ;
- détail façon ardoise sur une section menu ;
- citation de façade très courte.

Ne jamais utiliser Caveat pour :
- les paragraphes ;
- les menus longs ;
- les titres H1 ou H2 principaux ;
- le corps de texte courant.

## Hiérarchie recommandée
- H1 : très lisible, fort, humain, pas trop fin.
- H2 : éditorial, chaleureux.
- H3 : sobre, clair.
- Body : 16–18 px mobile/desktop selon contexte.
- Line-height généreux pour un rendu calme.

## Interdits
- typo tech startup ;
- typo luxe trop fine ;
- typo enfantine ;
- typo manuscrite illisible ;
- trop de styles différents ;
- texte gris trop clair.

## Règle agent
La décision typographique est finale :
- `Cormorant Garamond` pour les titres ;
- `Source Sans 3` pour les textes courants ;
- `Caveat` pour les accents manuscrits courts uniquement.
